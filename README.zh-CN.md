# Link Topology Explorer（link-topology）

[English](README.md) · 简体中文

通用站点内链拓扑工具：对**任意站点**运行，零站点耦合。CLI 抓取分析 + 单文件交互式产品 UI（Link Topology Explorer）。

- 以 sitemap（`/sitemap.xml` → `/sitemap-index.xml` → 子表递归）发现页面；站点无 sitemap 时退化为从根页面沿站内 `<a>` 链接 BFS 爬取（归一化路径 404 时自动补尾斜杠重试，适配 pretty-URL 静态站）。
- 逐页抓取 HTML，只抽取锚点作用域 `href`（忽略 src / canonical / 外链 / 资产扩展名），归一化 fragment / query / 尾斜杠。
- **全站导航边（chrome）数据驱动识别**：被 ≥ 阈值（默认 0.9）的已抓页面指向的目标视为导航，在拓扑与度数统计中剔除，不硬编码任何站点的导航清单。
- 集群按 URL 路径前 N 段聚合（`--cluster-depth`）。
- 输出：`topology.json`（节点 / 边 / 孤儿页 / 入度榜 / 跨集群边 / 抓取失败清单）+ 集群级 `topology.mmd`（`--full` 追加页级图，供 mermaid.live 等使用；HTML 产品不依赖它们），stdout 打印摘要。

## 用法

```bash
node link-topology.mjs <base-url> [options]
# 或
npm run topology -- https://petguidecalc.com

# 常用选项
#   --sitemap <url>         显式 sitemap 地址（默认探测 /sitemap.xml、/sitemap-index.xml）
#   --out <dir>             输出目录（默认 node_modules/.cache/link-topology）
#   --concurrency <n>       并发抓取数（默认 6）
#   --timeout-ms <n>        单请求超时毫秒（默认 15000，失败重试 1 次）
#   --chrome-threshold <f>  全站导航边判定阈值（默认 0.9）
#   --cluster-depth <n>     集群聚合路径段数（默认 1）
#   --max-pages <n>         BFS 兜底模式页数上限（默认 500）
#   --full                  额外输出页级 topology-full.mmd
#   --include-chrome        Mermaid 保留全站导航边（虚线）
#   --help                  显示用法
```

退出码：抓取失败导致数据不全时为 1；拓扑分析结果本身不设失败门槛。

## Link Topology Explorer（产品 UI）

```bash
node render-html.mjs [--dir <输出目录>]
```

把 `topology.json` 编译成**单文件交互式产品** `topology.html`：图表引擎（Cytoscape.js + fCoSE 力导向布局）构建时内联（缓存于 `<out>/vendor/`，内联失败回退 CDN），产物离线可开、零站点耦合。UI 源码在 `report-ui/`（app.js / app.css），由 render-html.mjs 注入数据与引擎。

界面与交互：

- **顶栏**：集群 / 页面 / 数据三视图分段切换；全局搜索（`/` 聚焦，方向键 + Enter 选择，跳转并选中节点）。
- **左侧栏**（分区式排版）：概览指标瓦片（孤儿页为 0 时绿色显示）；集群导航（色块 + 页面数微型条形图 + `↗/↘` 跨集群计数，点击定位）；问题清单按严重度着色（孤儿页琥珀 / 零出链灰 / 抓取失败红——点击直接定位到图中节点或打开原 URL）。
- **画布**：力导向图（双尺度点阵底纹），滚轮缩放 / 拖拽平移 / 节点可拖动（悬停描边加重）。**集群视图**里所有集群为统一「淡色填充 + 集群色描边 + 集群色文字」圆角卡（同一视觉语言，暖色调压饱和均衡视觉重量）。**页面视图**里每个集群是一个淡色分组框（compound 父节点，fCoSE 复合布局自动收纳），页面归位其集群：框内弧线走线（密集纹理层）、跨框 taxi 直角走线（圆角转折，结构层）；非 sitemap 页降级为虚线 ghost。单击节点打开详情并高亮邻域（非焦点灰化、邻域边加粗，选中分组框则保留整框 + 边界边）；双击 = 集群下钻 / 打开原页面；点击空白取消。
- **标签 LOD 阶梯**（页面视图）：概览缩放只看分组框与节点形状；屏幕空间恒定的 HTML 覆盖层始终显示集群标题（白底胶囊 + 集群色边条，小集群居中锚定）与入度头部页名（深色胶囊，带碰撞避让，缩放 ≥0.55 后交给画布内标签）；普通页面短名（路径末段）放大后浮现。
- **侧栏 ↔ 画布联动**：悬停集群行，画布中对应分组框/卡片描边提亮；页面视图内点击集群行直接定位该分组框（不切视图）。
- **浮层**（磨砂玻璃质感）：画布控制条（右下角，缩放 −/适应/+、「含全站导航」虚线并入、「边权重 ≥N」过滤）；图例（左下角，可视化 swatch 网格，9 秒无交互自动收起为按钮，悬停不收起）；面包屑；tooltip（集群色边条）。
- **集群聚焦**（核心下钻）：从集群详情「聚焦集群子图」只渲染该集群成员 + 外部关联页（虚线 ghost 节点，弱化着色），替代全量长图；面包屑一键返回全站。
- **详情面板**：页面（入/出度指标瓦片、出链/入链完整清单，按入度带条形底纹，可点击跳转、直达原页面）；集群（内部链接/出入向瓦片、主要页面、出/入向跨集群跳转）。
- **数据视图**：入度榜、跨集群内容边、孤儿页、零出链页面、抓取失败五张表，路径均为新标签打开的真实链接。
- **导出**（顶栏右「导出」菜单，磨砂下拉 + toast 反馈）：**当前视图 PNG**（所见即所得——含当前缩放 / 过滤 / 高亮状态；画布位图 + 点阵背景 + 屏上覆盖层标注（集群胶囊 / 头部页名胶囊）按视口坐标重绘进位图 + 署名页脚）；**整图 PNG**（完整布局，分辨率自适应——8192px 边 / 24M 像素上限，自动 fit 后经 pan/zoom 换算标注坐标，已补偿 devicePixelRatio）；**页面清单 / 链接边表 / 集群汇总 CSV**（UTF-8 BOM，Excel 直接打开，页面表含 inSitemap / orphan / zeroOut 标记列）；**GEXF**（Gephi 原生，节点带集群配色与度数属性）/ **GraphML**（Cytoscape、yEd、NetworkX 通用图格式）；**原始数据 JSON**（与 topology.json 完全一致）。文件名统一 `link-topology-<域名>-<日期>.*`；数据视图下图像项自动禁用。
- **大站防护**（页面数 > 1500 自动启用，UI 明示）：**页面视图按「集群 → 类目组」两级下钻，任何入口的渲染规模都有界**——
  - 引导态（无聚焦）：头部集群快捷入口；集群 > 600 页时进入**类目目录面板**（纯 HTML，零渲染成本）。
  - **隐式类目结构发现**：扁平目录（如电商 `/products/{slug}`）没有可用的路径分段，改为按每个非枢纽页的「最强内容入链来源」分组（≥5 页成组，计数降序 / 来源路径升序决胜，只算一次并缓存）。实测 petloverscentre 的 3931 页商品集群可还原 268 个类目组（覆盖 92% 单品，组均 ≤99 页），按来源集群分节展示（<3 组的来源合并为「其他来源」），另有热门枢纽快捷入口与覆盖率统计。
  - **目录双侧统一**（交互一致是设计目标）：类目来源集群（dog/cat/fish/… 自身 ≤600 页但拥有 ≥3 个类目组的集群）进入页面视图同样是**类目目录面板**——从大集群侧或物种侧进入都是同一条「集群 → 类目目录 → 组图」路径。来源目录提供「集群页面图」action（该集群自身页面全量成图，面包屑可逐级返回目录）；全量目录的分区头有「进入 X ↗」互链按钮直达对应来源目录。
  - **手势全局统一**：图中**类目来源页**（粗描边标记，hover 提示）双击直达其组图，与目录 chip、搜索路由、详情面板「查看其类目组」按钮同一目的地；**聚合集群块**双击进入该集群默认形态（有目录则面板）；其余页面双击打开原页面。
  - **类目组图**（主阅读视图）：来源类目页锚点（加粗描边）+ 组内单品真实节点 + 外部关联按**集群聚合块**呈现——电商单品页的面包屑会指向上百个类目页，逐页 ghost 会淹没主体；聚合后每集群一个带 `↗/↘` 合计次数的虚线块（单击看集群、双击聚焦该集群）。≤60 成员的组在 fit 后钳制缩放 ≥0.95，落地即可读成员名。
  - **热门总览图**：入度 Top 250 真实节点（大小按视图内头部缩放）+「长尾」聚合大节点（每页一条合计边，点开按入度列清单）+ 8 个头部集群块；长尾小组合集（<5 页的组）同样可一键成图。
  - **搜索路由**：任意路径按「当前图 → 所在类目组 → 热门图 pin 置入」逐级兜底；类目来源页直接命中其组图（锚点选中），来源目录集群的其余页进「集群页面图」定位；面包屑逐级返回（组/热门/集群页面图 → 目录 → 引导态）。
  - 集群数 > 60 时 ≤2 页的小集群折叠为一张虚线「长尾集群」聚合卡（边按计数聚合，点开可见成员清单并逐个定位）；聚焦视图按权重截断纹理边至 2500 条。
  - **布局与性能**：节点 > 250 或边 > 3000 改用确定性布局（组内按入度网格、组间 shelf 装箱，约 1 秒）；「集群页面图」是类目树 + 面包屑近团（104 页可达 1900+ 边），力导向会塌成中心毛球——边 > 1200 同走网格且页边透明度压至 0.09（实测 265ms 出图）；类目组用 fCoSE `draft` 档 + 关闭位移动画（约 1 秒）；热门图 LOD——概览只显示 HTML hub-chips 头部页名胶囊（屏幕恒定大小、按视图内 Top 20 标记），画布标签放大 ≥1.5 才浮现；`hideEdgesOnViewport` + `textureOnViewport` 保证万级边拖拽跟手（实测 20 次平移 0ms）；去重叠单轮推力设上限 + 最小穿透轴分离（防发散）。
  - **引擎内联依赖链**：cytoscape → layout-base → cose-base → cytoscape-fcose 依序内联——fcose 的 UMD 以 `window.coseBase` 为外部依赖（cose-base 又依赖 `window.layoutBase`），缺任何一环 fcose 会静默注册失败并回退内置 cose（布局质量显著劣化，复合图上可能崩溃）。
- **反爬站点说明**：带 Cloudflare 等交互质询的站点无法用 Node fetch 直接抓取（TLS 指纹不匹配，持有 cf_clearance 也无效）。可行做法是用真实浏览器过质询后，把页面内 fetch 注入 `collectTopology({ fetchImpl })`（本工具对 petloverscentre.com.my 即以此方式抓取 930/931 页，唯一失败页为需登录的会员页，已如实记录在 fetchFailures）。
- 控制台诊断句柄：`__linktopo.cy` / `__linktopo.state` / `__linktopo.clusterSkeleton` / `__linktopo.exports`。
